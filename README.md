# Kanban Project

Проєкт для демонстрації управління завданнями за методологією Kanban.

## Features
- Kanban board
- Task management
- WIP limits

## Робота з GitHub

Проєкт використовує Git для контролю версій та GitHub
для зберігання віддаленого репозиторію.

Основна гілка: main
Гілка розробки: brach-1

Основні команди:
- git status — перевірка стану
- git add — додавання змін
- git commit — збереження версії
- git push — відправлення на GitHub
- git pull — отримання змін
